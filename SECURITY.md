# Security

This repository contains anonymised production-derived configuration.
No credentials, private keys, or operator data are published — see `.gitignore`
for the complete exclusion list.

## Reporting accidental disclosure

If you believe a sensitive value (key, token, real IP, domain name) was
accidentally committed, please report it privately:

**Contact:** lionel@rousseau.kr

Do not open a public issue for security-sensitive findings.
